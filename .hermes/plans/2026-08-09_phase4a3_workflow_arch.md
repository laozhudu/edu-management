## 一、目标架构（四大域）

### 🧑‍🏫 管人（人 = 学生 + 教师，对称结构）
| 域 | 标签（二级） | 说明 |
|----|------------|------|
| **学生管理** | 学生信息 / 新生注册 / 学籍变动 / 升留级毕业 | 已有，保持 |
| **教师管理** | **教师信息 / 教师入职 / 教师变动 / 教师退休** | 对齐学生：当前仅"教师列表+任课"，补生命周期 |

### 📋 管事（教学业务）
| 域 | 标签（二级） |
|----|------------|
| 班级科目 | 班级科目 |
| 教室位置 | 教室位置 |
| 考试管理 | 考试管理/分考场座位/监考安排/准考证（内部工作流） |
| 成绩管理 | **成绩录入**（内部tab：编辑/概览/可视化分析）/ **成绩统计**（独立统计页） |

### 🧰 管工具（底座集中地，新增「报表工具」域）
| 域 | 标签（二级） | 说明 |
|----|------------|------|
| **报表工具** | 报表生成 / 模板管理 / 批量打印 | ReportView 整体迁入（从成绩域/系统域集中出来） |
| 导入导出 | 学生导入 / 教师导入（向导） | 复用 ImportWizard |

### ⚙️ 管系统（系统底座）
| 域 | 标签（二级） |
|----|------------|
| 系统设置 | 学期设置 / 用户权限 / 数据维护 / 系统设置 / 初始化 |

## 二、关键改动

| 项 | 内容 | 依据 |
|----|------|------|
| R1 | **报表工具域新建**：ReportView（报表生成/模板管理/批量打印）从 score_stats 错挂处 + system.report 集中到新域 | 底座集中 |
| R2 | **成绩统计视图新建**：ScoreStatsView（总分/均分/及格率/分布/班级对比），score_stats 不再指向 ReportView | 成绩纯净 |
| R3 | **教师对齐学生**：Teacher model 加 status（在职/离职/退休）+ 教师变动记录表；教师域 4 标签（信息/入职/变动/退休） | 教师≈学生 |
| R4 | ui_config.json 重构为四大域（管人/管事/管工具/管系统 分组） | 工作流视角 |
| R5 | 桌面 registry + Web 模板对齐 | 双端一致 |

## 三、实施顺序（先易后难，每步可验收）

1. **R1+R2 报表工具域 + 成绩统计**（纯配置+新统计视图，不动 model）→ 立即可用
2. **R4 ui_config 四大域重组**（配置层，Web 自动跟随）→ 双端导航成型
3. **R3 教师生命周期**（model + 迁移 + 4 标签视图 + CRUD API）→ 最大改动，最后做
