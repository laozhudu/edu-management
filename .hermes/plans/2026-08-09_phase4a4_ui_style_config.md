# 第四阶段（A4）方案：界面样式可视化配置（菜单/字体/登录框）

> 2026-08-09 · 用户反馈："还有管理界面（样式配置）没出来"，"代码有写但没显示，前期要求可配置化/零代码"

## 一、现状（实机盘点）

**ui_config.py 已完整可配置化**（代码已写）：
- `ThemeConfig`：品牌/强调色/侧栏背景/悬浮/密度
- `TopBarConfig`：学期切换/搜索框/快捷键/命令面板
- `LoginDialogConfig`：登录框宽高/边距/字体/圆角/品牌区（20+ 字段，注释明确"零代码 UI 可配置"）
- `StatusBarConfig`：状态栏左右项

**但：桌面端/Web 端都没有编辑这些配置的界面！**
- system_config 视图只显示服务状态/审计日志，无样式配置
- 桌面侧栏、登录框、状态栏都从 ui_config.json 读配置（已生效）
- **缺"配置保存"界面**：只能手改 JSON，违背"可配置化/零代码"

## 二、方案：新增「界面样式」配置界面

### 后端（config.py）
- **新增 `POST /api/config/save-ui`**：接收 UI 配置片段（theme/login/topbar 等），**写回 ui_config.json**（合并更新）+ 更新内存配置 + reload 生效
- 复用已有 GET config + POST /reload

### 桌面端（新界面）
- system_config 视图加「界面样式」Tab（或独立视图），表单化编辑：
  - **外观主题**：强调色/侧栏背景/菜单 hover/内容背景/密度（下拉 compact/comfortable）
  - **登录框**：宽高/字体大小/圆角/品牌标题/品牌副标题大小（30+ 字段，分组展示）
  - **顶部栏**：学期切换开关/搜索框开关/快捷键
- 「保存并生效」→ 调 config/save → reload → 桌面即时刷新

### Web 端（system_config.html 加 Tab）
- 同字段表单，存档后调 save API，前端提示已生效
